# Sehaty - Secure Medical Records Platform

Sehaty is a secure, robust Spring Boot application designed for managing and sharing personal medical records. It provides a platform for users to upload their medical documents, which are then encrypted and stored securely. The system's core feature is the ability to generate time-limited, secure sharing sessions for medical files via QR codes, making it easy to grant temporary access to healthcare providers.

---

## ✨ Core Features

- **Secure User Authentication**: End-to-end registration and login system using JWT (JSON Web Tokens) for stateless, secure sessions.
- **Encrypted File Management**: Upload, view, and delete medical files. Sensitive information like patient names and file details are encrypted at the application level before being stored in the database.
- **Secure QR Code Sharing**: Generate time-limited QR codes to share specific medical documents. Access is automatically revoked when the session expires.
- **HIPAA-Ready Auditing**: A comprehensive audit trail logs all access and modifications to sensitive data, a foundational requirement for HIPAA compliance.
- **Robust Security**: Implements multiple layers of security, including field-level encryption, rate limiting to prevent abuse, and secure password hashing with Argon2.
- **Dynamic Configuration**: Key application settings are externalized in `application.properties`, allowing for easy management across different environments (dev, staging, production).
- **API Documentation**: Integrated Swagger UI for clear, interactive API documentation.

## 🚶 User Journey

The platform is designed to be intuitive for both patients and healthcare providers.

### The Patient's Journey

1.  **Registration**: A new patient registers for an account using their name, email, and a secure password.
2.  **Login**: The patient logs in to receive a JWT, granting them access to the platform's features.
3.  **File Upload**: The patient uploads their medical documents (e.g., lab results, radiology images, prescriptions). Each file is assigned a category and is securely encrypted upon upload.
4.  **File Management**: The patient can view a list of all their uploaded documents or delete them as needed.
5.  **Initiate Sharing**: When visiting a doctor, the patient selects the specific documents they wish to share and creates a secure sharing session.
6.  **Generate QR Code**: The system generates a unique, time-limited QR code for the session.
7.  **Share with Provider**: The patient presents this QR code to their healthcare provider.

### The Healthcare Provider's Journey

1.  **Scan QR Code**: The provider scans the QR code presented by the patient using any standard QR code scanning app.
2.  **Secure Access**: The QR code opens a secure, read-only web page displaying the shared medical documents.
3.  **Review Documents**: The provider can view the patient's files directly in the browser.
4.  **Session Expiration**: After a set time (e.g., 15 minutes), the session automatically expires, and the link generated by the QR code becomes invalid, ensuring the patient's data remains private.

## 🚀 Setup and Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/bassam207/Sehaty.git
    cd Sehaty
    ```

2.  **Set up the PostgreSQL Database**
    - Create a new PostgreSQL database named `Sehaty`.
    - The application uses the credentials `postgres` / `Bassam207`. You can change these in the `application.properties` file.

3.  **Configure Environment Variables**
    The application requires a secret key for JWT generation. Set this as an environment variable:
    - **For Linux/macOS:**
      ```bash
      export JWT_SECRET="your-super-secret-and-long-jwt-key"
      ```
    - **For Windows:**
      ```bash
      set JWT_SECRET="your-super-secret-and-long-jwt-key"
      ```
    > **Important**: Choose a long, complex, and unique secret for your production environment.

4.  **Update `application.properties`**
    Open `src/main/resources/application.properties` and ensure the following properties match your local setup:
    - `spring.datasource.username` & `spring.datasource.password`
    - `cloudinary.cloud-name`, `cloudinary.api-key`, `cloudinary.api-secret`
    - `sehaty.encryption.key`: **For production, this key MUST be externalized and managed securely (e.g., via environment variables or a secret manager).**

5.  **Build and Run the Application**
    ```bash
    mvn clean install
    mvn spring-boot:run
    ```
    The application will start on `http://localhost:8089`.

## 🔒 Security Features

Sehaty is built with a security-first mindset.

- **Authentication**: All protected endpoints require a valid JWT token passed in the `Authorization: Bearer <token>` header.
- **Encryption at Rest**: Sensitive fields in the database (e.g., `User.name`, `MedicalFile.displayName`) are automatically encrypted by the application using AES encryption. This protects the data even if the database is compromised.
- **Data Integrity**: The application uses `orphanRemoval=true` to prevent orphaned records in the database, ensuring data consistency.
- **Audit Trail**: All actions on sensitive data (viewing, uploading, deleting files) are logged with user context, providing a clear audit trail.
- **Rate Limiting**: Protects against brute-force attacks and abuse by limiting the number of requests a user or IP address can make in a given time window.
